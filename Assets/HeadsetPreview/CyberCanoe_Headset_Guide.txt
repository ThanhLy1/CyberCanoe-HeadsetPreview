CyberCanoe headset guide

The current VR setup and usage instructions are in README.txt in this folder:

    Assets/HeadsetPreview/README.txt

That README covers Meta Quest and SteamVR connections, turning VR on and off,
recentering, preview calibration, troubleshooting and LAVA presentation builds.

For Meta Quest PC preview, install XR Plugin Management and Unity OpenXR Meta
before importing the add-on. Let Unity install their dependencies, including
OpenXR and Input System. Keep the class project's existing URP and Unity UI.
Follow BEFORE IMPORT in README.txt for the steps and SteamVR alternative.

Start with BEFORE IMPORT, then ADD PREVIEW TO YOUR SCENE. The VR mode switch
is the checkbox beside the Cyber Canoe Headset Simulator component's title on
CyberCanoe_HeadsetSimulator. Keep global Initialize XR on Startup off and the
simulator's Initialize XR field on so the component controls headset startup.
